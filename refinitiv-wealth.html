The Problem

Thomson Reuters One (TR1) was the desktop tool Wealth Advisors used to manage clients, households and portfolios. It needed a technology and usability refresh, and a move into Refinitiv Workspace.

In practice, that meant:

  • A desktop-only product, with no support for other screens
  • Client-facing users, not traders at a terminal
  • A design system built for dense, dark trading screens
  • Existing users and new customers to migrate

Workspace’s design system was built for the left: dense, dark and read by specialists. Advisors needed the right: fewer figures, more space, and a light theme that didn’t exist yet.

The Challenges

We didn’t start from scratch. The brief was an MVP built from existing research, so I started there, then ran workshops with stakeholders and users to agree what had to improve.

Whiteboard sketches were matched against user flows, and shared decisions were recorded as actions.

From there I planned the application at a high level: one screen or two, a single layout or several windows, and how advisors would build, save and switch between layouts.

Wireframes added detail at each level, refined with the PMs and POs, and a high-level prototype showed how navigation and interaction would work.

A lighter UI for client-facing work

Workspace’s design system was built for dense, dark trading screens. Wealth Advisors use the tool with clients, so they needed something cleaner and more open.

We had room to explore what that looked like, and it became the first implementation of Halo Light UI. I shaped the light theme, which Workspace didn’t have yet: bigger headline figures, more space, and charts that read at a glance, built on existing components wherever possible.

Building with offshore teams

I worked directly with the development leads in India, sharing designs against the release roadmap and holding regular reviews. Designs arrived in the order the team would build them, so hand-off kept pace with each release.

The Result

TR1 was reworked and integrated into Workspace, giving Wealth Advisors a tool they could use in front of clients. It was also where Halo Light UI started: a light theme I shaped, which Workspace hadn’t had before.

The product has been refined further since my involvement.
